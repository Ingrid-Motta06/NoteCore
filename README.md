# Projeto Pedagógico: Sistema de Controle de Anotações (NoteApp)

Projeto em Java 21 e Spring Boot estruturado para ser trabalhado em grupo via Git.

## Requisitos
- Java 21+
- MySQL Server
- Maven (ou Maven Wrapper)

## Estrutura do Projeto
- `Backend`: Controllers, Services, Repositories e Models configurados.
- `Database`: Configurações no `application.properties` para MySQL.
- `Testes`: Teste de integração JUnit/MockMvc e arquivo `requisicoes.http`.

## Como Executar
1. Certifique-se de que o MySQL está rodando localmente.
2. Ajuste o usuário/senha no arquivo `src/main/resources/application.properties`.
3. No terminal, execute:
   ```bash
   mvn spring-boot:run
   ```
